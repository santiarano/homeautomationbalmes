# StandByMePad

Native iPad shell for the StandByMe dashboard.

It bundles `../../webos-app` and opens `webos-app/index.html` full-screen in a native iPad app, so the iPad version stays visually aligned with the LG StandByMe app.

## Open In Xcode

```bash
cd ios/StandByMePad
xcodegen generate
open StandByMePad.xcodeproj
```

In Xcode, select your Apple developer team if it is not filled in automatically, then run on the iPad.
